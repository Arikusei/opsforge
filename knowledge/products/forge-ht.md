# ForgeHT — индустриальные смазки и СОЖ

Бренд: ForgeHT
Категория: жидкости для металлообработки, промышленные масла, смазки общего и специального назначения
OpsForge — официальный дистрибьютор.

Специальные смазки: высокотемпературные, водостойкие для тяжёлых условий, малошумные, для тросов, высокоскоростных подшипников, открытых зубчатых передач, автомобильные.

Промышленные масла: гидравлика, компрессорные, трансмиссионные, цепные, циркуляционные, железнодорожные, масла для шин.

Использовать, когда клиенту нужен широкий индустриальный ассортимент не из контура ForgeOil / ForgeFood, либо есть прямое указание на ForgeHT в регламенте.
