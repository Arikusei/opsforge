# Квалификация входящей заявки (продажи)

Цель: за 1 цикл превратить заявку с сайта, звонок PhonePBX или сообщение в TeamChat в карточку CRM с понятным следующим шагом.

Обязательные поля:
- компания и ИНН (если есть);
- отрасль: металлообработка / пищевка / транспорт / ж/д / нефтегаз / прочее;
- задача: СОЖ, индустриальное масло, пищевая смазка, покрытие, клей/герметик, универсальная смазка;
- объём и срочность;
- текущий бренд-конкурент;
- контакт ЛПР.

Правила маршрутизации:
- пищевой допуск NSF → линейка ForgeFood H1, тег `food`;
- прикипание, сухой узел, крепёж, антипригар → ForgeCoat, тег `coatings`;
- автопарк / масла ГСМ → ForgeFleet / ForgeOil, тег `fuels`;
- металлообработка, стойкость инструмента → ForgeSozh / ForgeCut, тег `metalworking`.

SLA: первичная реакция менеджера — в рабочее время Пн–Пт 9:00–18:00, иначе создать задачу «перезвон к открытию» и уведомление в TeamChat.
